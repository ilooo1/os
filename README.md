# 🚀 Vardosanidze OS v1.0

Лёгкая, сверхбыстрая операционная система для ПК на базе Linux без принудительных обновлений, с встроенным FPS-оверлеем и локальным ИИ.

🌐 **Официальный сайт:** https://ilooo1.github.io/os/

🖥️ **Рабочий стол (Web-демо):** https://ilooo1.github.io/os/desktop.html?v=5


### 📦 Состав системы (10 модулей):
- `desktop.html` — графический рабочий стол v3.0 с живым FPS-виджетом, V-Menu и сменой обоев.
- `gui.html` / `gui_center.py` — графическая панель управления системными модулями.
- `control_center.py` — консольный Центр управления v0.3 с встроенным FPS по умолчанию.
- `ai_core.py` — локальный ИИ-помощник с долговременной JSON-памятью.
- `setup_os.sh` — скрипт авторазвёртывания системы и базового софта (Steam, Discord, Telegram, OBS).
- `optimize_pc.sh` — оптимизация ядра Linux (`sysctl`), сети BBR и настройка MangoHud FPS для AMD RX 570.
- `network_shield.py` — сетевой модуль для снижения пинга и обхода DPI.
- `hw_monitor.py` — мониторинг процессора, памяти, диска и температурных датчиков ПК.
- `index.html` — официальный релизный портал проекта.
