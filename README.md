# 🚀 Vardosanidze OS

Лёгкая, сверхбыстрая операционная система нового поколения без навязчивых обновлений и со встроенным локальных
🌐 **Официальный сайт:** [https://ilooo1.github.io/os/](https://ilooo1.github.io/os/)


### ⚡ Главные особенности:
- **Минимальный вес:** ~6 ГБ на диске и ~500 МБ ОЗУ в покое.
- **Полный контроль:** Никаких принудительных обновлений — только по кнопке.
- **Встроенный ИИ:** Локальный ассистент без слежки и отправки данных в облако.
- **Сетевые модули:** Удобная настройка сети и DPI в один клик.

👨‍💻 **Разработчик:** Илья Вардосанидзе
